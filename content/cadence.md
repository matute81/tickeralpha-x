# Cadence

Target: about 5 posts on a quiet weekday, 7–8 on CPI / NFP / FOMC / mega-cap earnings days. Skip empty conditional slots. Never pad.

Saturday: no job. Friday next-session = Monday.

## Always on — weekdays

| Slot | Window | File | Distinct job |
|------|--------|------|----------------|
| Next session | Pre-open, before 9:30 ET | `drafts/YYYY-MM-DD-am.md` | Tomorrow’s (or Monday’s) calendar, prior-close levels, what would change the tape |
| Session recap | After the close | `drafts/YYYY-MM-DD.md` | Full log: indexes, drivers, data, bottom line |
| Story of the day | After the close | same close file | One narrative. Recap is the log; this is the take |
| Movers and why | After the close | same | 3–5 names with % and a verified reason when one exists |
| Cross-asset tape | After the close | same | 10y / 2s10s, dollar, gold, crude, VIX, and what that meant for equities |

## Conditional — skip if nothing clean

| Slot | When | File |
|------|------|------|
| Overnight | Asia/Europe actually moved | morning |
| How to read the print | 1–2 mornings before a high-impact US release | morning |
| Data print | High-impact US release that session | close |
| Earnings reaction | Mega-cap or a cluster that moved the index | close |
| Breadth / the index lied | SPX vs Russell (or mega vs the rest) disagree in a meaningful way | close |
| Engagement | 2–3x / week, tied to the calendar | close or morning |

## Weekly extras

| Slot | When | File |
|------|------|------|
| Week ahead | Sunday | `drafts/YYYY-MM-DD-week-ahead.md` |
| Week wrap | Friday after close | close file |

## High-impact US prints (for conditionals and Sunday)

CPI, core CPI, PPI, PCE / core PCE, nonfarm payrolls, unemployment rate, initial claims, GDP, retail sales, ISM manufacturing / services, consumer confidence, housing (existing / new / starts / permits), FOMC / rate decision / minutes / chair testimony.

## Suggested post order on X

1. Overnight (if any), then how-to-read-the-print (if any), then next session — before the open
2. Data print — after the number, not before
3. Recap, story, movers, cross-asset — after 16:00 ET
4. Earnings reaction — after the bell or next morning if it is after-hours
5. Friday wrap after Friday’s recap cluster
6. Sunday week-ahead anytime Sunday
